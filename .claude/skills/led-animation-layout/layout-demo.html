Ring layout demo

The concepts from the led-animation-layout skill. The 12 big rings stand in a circle and ring r sits at r:30 on a clock. Each big ring is itself a circle of 12 small rings. The dashed small ring (0) faces the center of the installation.

1. Geometry

Click a ring to see its partners, or play the rotation.

2. Two-part layouts

Split the installation into parts A and B by combining a big-ring split (which rings are in group G1 / G2) with an inside split (which half of each ring, s0 / s1), then pick how they combine. Choosing Whole ring or None gives the single-level splits. Whole rings: each big ring belongs entirely to A or B. Segments: inside a big ring you can't pick arbitrary pixels, only whole segments. A group can use several segments (e.g. small rings "0", "1" and "11"), and different big rings can use different segments. Every pixel of the installation is shown here.

3. Segments inside one big ring

Each big ring is a circle of 12 small rings with 12 pixels each (144 pixels). A snake effect travels along the segment's relPos, so the segment decides the shape of the motion. Dim pixels are not in the segment.

4. Gallery

Every option as a still picture (A = blue, B = orange, dark = off). Click one to load it into panel 2 and animate it.

5. Four-part layouts

The same idea with four parts, A, B, C and D. Build them either from 4-way splits (four ring groups and/or four quarters inside each ring) or as a 2×2 cross of any two-way big split with any two-way inside split from panel 2.

6. Motion for two-part layouts

Give each part its own snake. With a ring-level split each group of rings is fully independent: any path, direction, tempo and wave. With an inside split both parts live in the same rings, and every effect on a segment touches all of its pixels, so they share one motion and differ only in color. Pick a preset or tweak each part.

7. Stacked snakes

    
Two snakes on the same rings, one on top of the other. The renderer (kivsee-render) applies effects in order to each pixel, so how the second snake lands on the first decides the look:
      Intersect (snake × snake: light only where both are lit),
      Add (snake then snake_brightness increase: both are visible, optionally in a second color via snake_hue),
      Shadow (snake_brightness decrease: a dark snake cuts through the light),
      Color band (snake_hue: a moving band of shifted color). Each layer can use a different path.
